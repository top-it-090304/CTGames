Экономическая стратегия с элементами казино-симулятора, разработанная на современном игровом движке Godot.

## Стек технологий
* **Игровой движок:** Godot Engine 4.4.1-rc1
* **Язык программирования:** GDScript
* **Интерфейс и графика:** Компоненты UI на базе встроенных Node2D/Control, кастомные 2D/3D ассеты

## 🚀 Ключевые особенности игры

* **Экономический менеджмент:** Управление балансом, распределение ресурсов и оптимизация логистики потока игроков.
* **Динамический UI:** Адаптивный и интуитивно понятный интерфейс, написанный с использованием сигналов (Signals) Godot для быстрой обработки событий.
* **Модульная архитектура:** Сцены разделены на логические блоки, что позволяет легко добавлять новые игровые автоматы и зоны.

## 📂 Структура проекта

Для удобства навигации по репозиторию основные ресурсы распределены по следующим папкам:

* `Materials/` — Скрипты интерфейса (`.gd`), сцены панелей управления, игрового автомата (`slot_machine_2d.tscn`) и логика рулетки.
* `Objects/` — 3D-модели, импортированные файлы (`.glb`) и их конфигурации для окружения.
* `textures/` — Графические ассеты, спрайты игровых элементов (cherry, lemon, seven, diamond и др.).
* `project.godot` — Главный файл конфигурации проекта Godot.

## 💻 Инструкция по развертыванию и запуску

Любой другой разработчик может запустить проект, выполнив следующие шаги:

### 1. Требования к окружению
* Установленный **Godot Engine 4.1.* и выше.
### 2. Клонирование репозитория
Склонируйте проект на локальный компьютер:
```bash
git clone [https://github.com/canceltell/CTGames.git](https://github.com/canceltell/CTGames.git)
cd CTGames
```
### 3. Импорт проекта в Godot

* Запустите Godot Project Manager.

* Нажмите кнопку Import (Импортировать) на панели справа.

* Нажмите Browse (Обзор), перейдите в папку с проектом и выберите файл project.godot.

* Нажмите Import & Edit (Импортировать и редактировать).

### 4. Запуск игры

* После того как проект откроется в редакторе Godot, нажмите F5 (или иконку «Play» в верхнем правом углу) для запуска главного экрана игры.

## 🎮 Игровой процесс и управление

### Суть игры
Игрок начинает с ограниченным стартовым капиталом. Его задача — выстроить прибыльное казино-инфраструктуру в Jackpot Jail. Основной источник дохода на данном этапе — игровой автомат.

### Как играть (Игровой цикл):
1. **Запуск и интерфейс:** При старте открывается главное меню/панель управления. Игрок видит свой текущий баланс.
2. **Взаимодействие с автоматами:** Переходя к игровому автомату, игрок может испытывать удачу или тестировать экономический баланс системы.
3. **Механика рулетки:** В модуле рулетки игрок делает ставку, покупает тотемы, которые дают шанс к выпадению и др., запускает вращение барабана и получает выигрыш или проигрыш в зависимости от выпавших комбинаций (спрайты `cherry`, `lemon`, `seven` и др.).

### Управление в игре:
## ПК (Godot):
* `Мышь (ЛКМ)` — основное взаимодействие с интерфейсом: нажатие кнопок меню, переключение панелей управления (`panel_2` – `panel_6`), выбор ставок и запуск вращения рулетки.
* `F5` — запуск игры из редактора Godot.
* `Esc` — (если реализовано) выход в главное меню или закрытие активной панели.
## Мобильный телефон (Основа):
* Все юзабельные кнопки показаны на экране
